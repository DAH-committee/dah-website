# 한림대학교 디지털인문예술전공 웹사이트

한림대학교 디지털인문예술전공의 공식 웹사이트입니다. 전공 소개와 교육과정, 구성원, 학생 활동, 공지사항, 자료실, 프로젝트 전시회와 공모전 정보를 한곳에서 운영합니다.

## 사이트에서 할 수 있는 일

- 전공의 비전·연혁·교수진·멘토와 교육과정 확인
- 공지사항과 자료실에서 학사·행사 정보를 확인
- 프로젝트 전시회, 공모전, 특강, 학생 성과와 포트폴리오 탐색
- 관리자 권한으로 전시·행사·콘텐츠·사용자·사이트 정보를 관리
- 전시 접수와 행사 신청을 온라인으로 처리

## 운영 구조

| 구분 | 구성 |
| --- | --- |
| 웹 프론트엔드 | React + Vite |
| API 서버 | Node.js + Express |
| 데이터베이스 | Neon PostgreSQL |
| 파일 저장소 | Vercel Blob |
| 웹 배포 | Vercel |

## 프로젝트 구조

```text
client/  웹사이트 화면과 관리자 대시보드
server/  API, 인증, 콘텐츠 관리, 파일 업로드
```

## 공동 관리

이 저장소는 전공 운영을 위해 공동 관리합니다. 작업 전에는 최신 변경사항을 먼저 받고, 기능 수정은 별도 브랜치 또는 Pull Request를 사용하는 것을 권장합니다. 운영 배포에 영향을 주는 환경변수·데이터베이스·파일 저장소 설정값은 저장소에 올리지 않습니다.

## 개발 실행

```bash
# 프론트엔드
cd client
npm install
npm run dev

# API 서버
cd ../server
npm install
npm run dev
```

배포 환경 설정은 Vercel과 Render의 환경변수 관리 화면에서 설정합니다.
