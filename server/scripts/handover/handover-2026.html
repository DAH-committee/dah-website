0. 문서 사용법

  • 오른쪽 여백 댓글: 원본 사진, 카드뉴스, 회의록 이미지 첨부 위치. 노란 형광 문장 클릭 시 해당 댓글 강조
  • 댓글 추가: 문장 드래그 → 툴바 댓글 버튼 → 사진 첨부 가능
  • 문서 탭: 왼쪽 패널. 탭 추가(+), 이름 바꾸기(두 번 클릭 또는 ⋮), 탭 복제, 삭제. 선택한 탭 다시 클릭 시 개요 접기
  • 버전 기록: 오른쪽 위 시계 아이콘. 수정한 사람·시각, 변경 문단 초록 표시, 이전 버전 복원, 버전 이름 지정
  • 다운로드: 파일 > 다운로드 (Word, PDF, 마크다운, 텍스트, 웹페이지). 파일 > Google Docs로 열기: 서식 복사 후 새 구글 문서에 붙여넣기
  • 계정 비밀번호: 기본 가림 상태. 눈 아이콘으로 표시, 복사 아이콘으로 클립보드 복사. 내보낸 파일에는 값 미포함
  • 편집 권한: 관리자 로그인 위원만 편집·댓글·탭 관리 가능. 비밀번호 열람자는 읽기 전용
  • 매년 할 일: 연도·날짜·명단 갱신, 바뀐 규칙은 해당 절에 바로 수정

4-1. 1월: 신입생 연락과 개총 준비 시작

  • 신입생(2학년 진입 시 디지털인문예술전공 선택 학생) 정보: 조교님께 단체 문자 발송 요청

  • 신입생 톡방 초대 멘트 작성 후 조교님께 전송

  • 참여 저조 대비(매년 저조): 연락처·정보 전달 요청 → 위원회 직접 연락, 톡방 입장 안내

  • 개강 총회 날짜: 전공주임교수님과 상의

회비 원칙: 물가와 식당 가격 고려. 예산 초과 절대 금지. 넉넉하게 걷은 뒤 무료 처리 시 환불 방식 가능

  • 미래융합스쿨 개강 총회: 위원장·부위원장 참석 권장

  • 동아리 재홍보: 개강 직전 또는 개강일

7. 전공 사이트로 전시회 접수 운영

2026-1까지 쓰던 구글 클래스룸, 구글 폼, Apps Script 접수: 폐지. 전공 사이트 접수로 일원화

7-1. 관리자 설정

  1. 관리자 페이지 로그인 (개인 계정)

  2. 사이드바 SYSTEM > 전시회 설정

  3. 접수 일정: 접수 시작, 접수 마감(이후 신규 접수 차단), 수정 마감(이후 신규·수정 전면 차단) 입력 → 일정 저장

  4. 회차·접수 대상 학기, 과목 관리 확인

  5. 화면 하단 접수 버튼 노출: '접수 버튼 노출 허용' 켜기 → 위치 '헤더' 또는 '플로팅' → 노출 설정 저장

  6. 원본 파일 보관 드라이브 연결 확인 (파일 보관함, 구글 드라이브)

기간 검증 기준: 서버 시각 (사용자 기기 시계 무관)

7-2. 참가자 흐름

  1. 사이트 헤더 접수 버튼 → 구글 로그인

  2. 참가 유형(개인·팀), 과목, 작품 정보 입력 → 접수

  3. 로그인 이메일로 접수 확인 메일 발송

  4. 마감일 자정까지 같은 구글 계정으로 수정 (참가 유형·과목·이메일은 읽기 전용)

  5. 원본 파일 직접 업로드: 온라인 전시만 PNG, 오프라인(인쇄) 전시 PDF + PNG

7-3. 접수 현황 확인

  • 전시회 설정 > 접수 현황 > 접수 현황 바로가기 (구글 시트 형태, 새 탭)
  • 시트 기능: 칸 수정, 행 추가·삭제, 검색, CSV·엑셀 내보내기
  • 마감 후 개인정보 초기화: 전시회 설정 화면

7-4. 자주 묻는 질문 정리

  • 오프라인 신청 시 온라인 별도 신청: 불필요. 오프라인 신청작은 온라인 자동 게시 (PNG 필수)
  • QR: 개수 제한 없음. QR 링크만 사이트 반영
  • 포스터 QR 연결 위치: 해당 작품 온라인 전시 페이지
  • 마감 이후 수정·추가: 불가
  • 참고: 피그마 인스타 게시물 페이지 FAQ 원고 (구글 클래스룸 기준 문항은 사이트 기준으로 갱신)
