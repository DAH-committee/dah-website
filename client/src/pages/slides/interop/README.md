# 클립보드 주고받기(구글 슬라이드, 문서, 키노트)

조사일 2026-10-12. 실제 구글 슬라이드(크롬)에서 복사·붙여넣기를 붙잡아 확인했다. 비공개 형식이라 구글이 바꾸면 깨질 수 있다. 깨지면 text/html로 내려간다.

## 구글 슬라이드가 복사할 때 싣는 형식

| 형식 | 내용 |
| --- | --- |
| `application/x-vnd.google-docs-drawings-object+wrapped` | 도형 명령 목록. 슬라이드·구글 그림끼리 붙일 때 쓴다. 우리가 읽고 쓰는 형식 |
| `application/x-vnd.google-docs-document-slice-clip+wrapped` | 구글 문서용 글 조각(dsl_spacers, dsl_styleslices). 쓰지 않는다 |
| `application/x-vnd.google-docs-internal-clip-id` | 같은 브라우저 안 내부 클립 id. 쓰지 않는다 |
| `text/html` | `<b style="font-weight:normal" id="docs-internal-guid-...">` 안에 인라인 서식 span. 그림은 data: PNG |
| `text/plain` | 글자 |

크롬은 웹 페이지의 copy 이벤트에서 `setData`로 넣은 임의 형식을 다른 탭의 paste 이벤트에 그대로 넘긴다. 그래서 DAH가 위 형식을 실으면 슬라이드가 자기 도형으로 붙인다.

## drawings-object 모양

```
{ "data": "{\"resolved\":[...명령],\"unresolved\":[...명령],\"autotext_content\":{}}" }
```
슬라이드는 `dih`(숫자), `edi`, `edrk`, `dct:"punch"`, `ds`, `cses`, `sm`도 싣지만 `data`만 있어도 붙는다(확인함). 글자를 바꾼 뒤 원래 `dih`를 그대로 둬도 붙었다(검사하지 않는다).

명령
- `[3, id, 종류, [a,b,c,d,tx,ty], [키,값,...], 쪽id]` 도형 만들기. 종류 108 글 상자, 6 직사각형, 7 둥근 직사각형, 8 타원, 98 삼각형, 72 오른쪽 화살표, 153 선, 3 그림
- `[15, id, null, 위치, "글자"]` 글자 넣기. 문단은 `\n`
- `[17, id, null, 시작, 끝, [], [키,값,...]]` 서식. 문단 서식은 문단 끝 `\n` 자리 한 칸(마지막 문단은 글자 길이 자리)
- `[41, id, null, 목록id, [단계, [17,글머리종류(9 기호, 10 숫자, 13 영문, 15 로마),25,0,36,"%0.",37,"●"], [], ...]]` 목록 정의

단위: 1 = 25 EMU(1/508 pt). 16:9 슬라이드 365760 x 205740. DAH 1px = 190.5. 도형 기본 크기 120000(3,000,000 EMU)에 행렬을 곱한다(a=sx·cos, b=sx·sin, c=-sy·sin, d=sy·cos). 그림은 속성 8·9(원래 px)에 곱한다(1px = 381).

도형 속성: 0 조절값(둥근 모서리, min(w,h) 대비 /100000), 14 채우기 종류(0 없음), 15 채우기 색, 16 채우기 불투명도, 18 테두리 종류(0 없음, 1 실선), 19 테두리 색, 22 테두리 두께(1px=381), 29 선 끝(5 속이 찬 화살표), 44 세로 정렬(0 위, 1 가운데, 2 아래), 39 그림 주소, 8·9 그림 원래 크기
글자 속성: 0 굵게, 1 기울임, 2 밑줄, 20 취소선, 4 색, 5 글꼴, 6 크기(pt), 8 링크
문단 속성: 12 정렬(2 가운데, 3 오른쪽, 4 양쪽), 11 줄 간격 %, 25 목록 단계, 27 목록 id, 13·28 들여쓰기(pt)
색은 `resolved`에 '#RRGGBB', `unresolved`에 테마 참조([null, n])가 들어간다. 읽을 때는 resolved를 쓴다.

## 붙여 넣기 결과(확인함)

- DAH가 만든 drawings-object → 슬라이드에 편집 가능한 글 상자·도형·선·그림으로 붙는다. 자리·크기·회전, 굵게·기울임·밑줄·색·크기·글꼴, 링크(클릭·수정 가능), 글머리·번호 목록, 채우기·투명도·테두리·둥근 모서리 모두 유지.
- 그림은 슬라이드 서버가 주소에서 받아 온다. 공개 https 주소여야 한다(구글 서버가 못 받는 주소는 경고 삼각형).
- text/html만 있으면 → 슬라이드 왼쪽 위에 글 상자 하나. 굵게·색·크기·기울임·링크·글머리는 남고 자리와 문단 정렬은 사라진다.
- PNG + text/html이 함께 있으면 → 슬라이드는 HTML을 쓴다(HTML 속 img 주소를 받아 온다). 그림으로 붙이려면 PNG만 싣는다.
- 슬라이드 → DAH: 같은 형식을 읽어 글·도형·선·그림으로 바꾼다. 테두리 있는 도형 안 글은 도형과 글 상자를 묶음(group)으로 만든다.

## 그 밖의 앱

- 구글 문서 → DAH: text/html(위와 같은 docs-internal-guid 꼴). 바깥 `<b style="font-weight:normal">`는 굵게가 아니다. 링크·굵게·기울임·목록을 살린다. 기본 검정 글자는 테마 글자색으로 바꾼다.
- 키노트: 크롬은 맥 클립보드에 HTML과 글자만 쓴다(RTF 없음). 키노트는 HTML을 서식 있는 글 상자로 붙인다. 도형은 그림(PNG)으로만 넘길 수 있다(copySelectionAsImage). 키노트에서 복사한 글은 크롬에 text/rtf 또는 text/html로 들어온다. rtf.js가 RTF를 읽는다.
