## QUERY

- 머리글 수 인수 생략 = 자동 감지(데이터 형식이 다른 첫 행을 머리글로): 인수 1, 생략, -1 은 같은 결과, 0 이면 머리글 행을 데이터로 취급(결과에 머리글 없음).
- 집계 열 이름은 "sum 점수", "count 이름", "avg 점수"(함수명 + 공백 + 원래 열 이름). `label count(A) 'n'` 으로 바꿈. `C*2` 의 열 이름은 "product(점수2())", `sum(C)/count(C)` 는 " quotient(sum 점수count 점수)" 처럼 어색하게 나온다.
- 문법 순서: `limit 2 offset 1` 만 되고 `offset 1 limit 2` 는 #VALUE!. `select count(*)` #VALUE!(별표 집계 없음). `select A,,C` #VALUE!.
- `month(D)` 는 0 부터(1월 = 0). `dayOfWeek` 는 일요일 = 1. `where C > '80'`(숫자 열과 문자 비교)은 빈 결과(머리글만). 일치 없음이면 머리글 한 줄만 남는다.

INDEX/CHOOSE 범위 밖이 #NUM!, 잘못된 정규식이 #REF!, REGEXMATCH 가 숫자 입력에서 #VALUE!, `\p{Hangul}` 가 #REF!, `COUNTIF(C1:C12,"~~x")` = 0, `=B1:B3`(단독 범위) #VALUE!. 내가 알던 구글 동작과 달라서, 붙여 넣기 과정(백슬래시, 문자열 변환) 때문에 생긴 아티팩트일 수 있다. `observe/README.md` 의 재실행 절차로 같은 값이 나오는지 확인하고, 엔진(SE)은 이 항목을 "관찰값과 일치" 필수 조건에서 빼고 따로 둔다.
