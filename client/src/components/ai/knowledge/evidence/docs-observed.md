# 구글 문서 관찰 (내보내기 구조, 붙여 넣기)

관찰일 2026-10-12. 내 계정에 스크래치 문서 "[테스트] AI 관찰 문서"를 만들고, 제목 1~6, 글자 서식, 5단계 중첩 글머리 목록, 번호 목록, 병합 칸이 있는 표, 정렬 세 가지, pre, 인용, 가로줄, 이모지를 담은 HTML 을 클립보드(text/html)로 붙여 넣었다. 문서 개요(탭 왼쪽)에는 제목 1~6 이 모두 단계별로 잡혔다(화면 확인). 그다음 문서의 내보내기 주소 `https://docs.google.com/document/d/<id>/export?format=html|txt|md|docx|odt` 를 로그인된 탭에서 한 번씩 받았다(상태 200, docx 217622바이트, html 13104바이트, md 538바이트, txt 438바이트, odt 3234316바이트). 관찰 후 문서는 휴지통으로 옮겼다.
미확인: 댓글과 제안(수정 제안) 모드의 내보내기 표현(스크래치 문서에 댓글을 만들지 않았다), 스마트 칩(@사람, 날짜, 드롭다운) 표현, 각주, 머리글/바닥글, 이미지 설정, 다단.

## 형식별 결과

md (`format=md`, 서버가 만든 Markdown)
- 제목 1~6 이 `# `~`###### ` 로, 제목 줄 안의 글자는 `**굵게**` 로 감싸져 나온다(제목 글자가 굵게 서식이라서).
- 굵게 `**`, 기울임 `*`, 취소선 `~~`, 링크 `[글](https://example.com/)` 로 나오고, 밑줄, 위첨자, 아래첨자, 형광 표시는 글자만 남고 사라진다(H2O, x2 로 출력). `<code>` 는 백틱 코드.
- 글머리 목록은 `* `, 번호 목록은 `1. `, 중첩은 공백 두 칸씩 들여쓰기.
- 표는 Markdown 표, 병합 칸은 풀려서 빈 칸이 된다. 가운데/오른쪽/양쪽 정렬은 사라진다. 인용은 `> `, 가로줄은 `---`.

txt (`format=txt`)
- 파일 맨 앞에 BOM(U+FEFF), 줄바꿈은 CRLF. 제목은 서식 없이 한 줄. 목록은 `* ` 와 `1. ` 에 3칸 단위 들여쓰기. 표 칸은 탭으로 이어진다(표가 있는 줄이 어긋남). 가로줄은 밑줄 문자 줄로 나온다.

html (`format=html`)
- 제목은 `<h1>`~`<h6>`, 문단은 `<p class="cN">`, 서식은 클래스(`c2`, `c15` 등)로 `<style>` 안에 모아 둔다(인라인 style 아님). 글자는 숫자 문자 참조(`&#51228;`)로 인코딩되어 나온다.
- 링크는 `https://www.google.com/url?q=<원래 주소>&sa=D&source=editors&ust=...&usg=...` 형태의 구글 리다이렉트 주소로 감싸진다(원래 주소가 그대로가 아님). 링크 글자는 별도 span.
- 목록은 한 목록이 아니라 단계마다 별도 `<ul class="lst-kix_… start">` 로 나뉜다(중첩 `ul` 안에 `ul` 이 아님). 각 단계 `<li class="…li-bullet-0">`. 글머리 모양은 CSS 의 `:before` 내용(●, ○, ■)으로 그려진다.
- 표는 `<table><tr><td colspan rowspan>`, 칸 안은 `<p>`. 정렬과 간격은 클래스에 있다.

docx (`format=docx`)
- 제목은 `w:pStyle` Heading1~Heading6, Title, Subtitle 스타일이 정의되어 있다.
- 쪽 설정(이 스크래치 문서의 기본): 용지 `w:pgSz w=11909 h=16834`(A4 세로, twip 단위, 210mm x 297mm), 여백 위/아래/왼/오른쪽 모두 1440 twip(1인치, 25.4mm), 머리글/바닥글 거리 720 twip. 한국어 계정이라 용지가 A4 로 잡힌 것으로 보인다(미확인: 계정 지역에 따른 기본값인지).
- 본문 글꼴은 이 문서에서 "Arial Unicode MS" 로 쓰였고(붙여 넣은 HTML 에 글꼴을 지정하지 않았음), 제목 1 은 굵게, 23pt(sz 46)로 기록되었다. 문서 기본 글꼴 크기는 화면에서 11pt(툴바 11, 글꼴 Arial).

## 붙여 넣기 (text/html 클립보드)

- 제목 1~6, 중첩 목록(5단계까지 확인), 번호 목록, 표(병합 포함), 정렬, 링크, 굵게/기울임/밑줄/취소선, 위/아래첨자, 형광, 코드(백틱 글꼴), pre, 인용, 가로줄, 이모지가 모두 구글 문서에 들어왔다(화면과 내보내기로 확인).
- 클립보드의 비공개 형식(`application/x-vnd.google-docs-document-slice-clip+wrapped`)은 `client/src/pages/slides/interop/README.md` 에 이미 정리되어 있어 다시 조사하지 않았다.

## 우리 문서 편집기와 비교

- 구글은 제목 6단계, 우리는 `StarterKit heading levels [1,2,3,4]` 로 4단계다. 구글 문서/마크다운을 가져올 때 5, 6단계 제목은 4단계로 합쳐야 한다.
- 구글 목록은 중첩 깊이가 5단계 이상 가능(관찰 5단계, 구글 최대는 미확인). 우리 insert_blocks 의 목록 depth 는 0~3(4단계)이다.
- 구글 md 내보내기는 밑줄, 형광, 위/아래첨자를 버린다. 우리 문서에서 md 로 내보내거나 AI 가 md 로 요약할 때 같은 손실이 있음을 감안한다.
- 구글 html 의 링크는 google.com/url 리다이렉트로 감싸져 있다. 가져올 때 `q=` 값을 풀어 원래 주소를 써야 한다.
- 구글 docx 기본 용지는 A4, 여백 25.4mm. 우리 set_page_setup 기본값과 비교할 것(우리 값은 이 조사에서 읽지 않음).
